# Matrix Screensaver (Windows)

Скринсейвер в стиле фильма «Матрица» для Windows 10/11. 
Дождь из символов (катакана, латиница, кириллица, цифры, спецсимволы), 
поверх которого «проявляется» надпись **THE MATRIX HAS YOU** за счёт 
эффекта выпуклой линзы: символы, попадающие внутрь контура букв, 
рисуются крупнее и ярче.

## Что внутри

- Поддержка двух мониторов: «THE MATRIX» центрируется на левом, 
  «HAS YOU» — на правом. Окно без рамки растягивается на весь 
  виртуальный рабочий стол.
- Хаотичная скорость колонок: медленные «сосульки», обычный дождь 
  и быстрые «искры» (экспоненциальное распределение).
- Цепочка шрифтов через `MultiFace`: пользовательские шрифты 
  из папки `fonts/` + системный Consolas как fallback.
- Выход по любой клавише, кнопке мыши или движению курсора.

## Требования

- Windows 10 или 11 (64-bit)
- Go 1.21+ (только для сборки)
